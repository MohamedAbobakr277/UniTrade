## 2026-08-28 - Dynamic aria-labels and tooltips for icon-only toggle buttons\n**Learning:** When an icon-only button represents a toggleable state (e.g., 'favorite' vs 'unfavorite' in Material UI), setting a static aria-label isn't enough. Users need context about what the button currently does. Using a dynamic `aria-label` and a `Tooltip` with a dynamic title ensures both screen reader users and sighted users understand the current state and the action they are about to take.\n**Action:** For all toggleable icon-only buttons (like favorites, bookmarks), wrap the IconButton in a `<Tooltip>` and use ternary operators for both the Tooltip `title` and the button's `aria-label` based on the active state.
