## 2024-10-26 - Add ARIA labels and Tooltips to Navbar Icon Buttons
**Learning:** Icon-only buttons lacking `aria-label` attributes and tooltips reduce both accessibility for screen readers and discoverability for visual users. Strict ESLint CI environments enforce resolving unused variables and impure functions (like `Date.now()`) to maintain code quality.
**Action:** Always verify that icon-only buttons have descriptive `aria-label` attributes and visual tooltips. Ensure local linting is clean before submitting to avoid CI failures.
