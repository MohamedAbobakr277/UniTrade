## 2024-03-21 - Accessible Absolutely Positioned IconButtons
**Learning:** Material UI's `<Tooltip>` safely clones its child and injects necessary event handlers and refs without adding extra wrapper DOM elements. This allows absolutely positioned elements like `<IconButton>` inside a relative container to be wrapped directly with `<Tooltip>` without breaking the layout. Additionally, when an icon-only button changes state (e.g., "favorite" vs "unfavorite"), providing dynamic `title` and `aria-label` texts based on the state enhances the experience for both sighted users and screen readers.
**Action:** Always wrap icon-only `<IconButton>` components with a `<Tooltip>` (which provides the visual label on hover) and ensure the `<IconButton>` has a matching `aria-label` (for screen readers), especially for buttons with absolute positioning where adding extra DOM wrappers might break the design.
